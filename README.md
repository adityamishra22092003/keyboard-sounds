# Keyboard Sounds

A web application that plays keyboard sounds using React and Radix UI components.

## Features

- Custom select dropdowns using Radix UI
- Modern React (v19) setup
- Modular component structure
- Easily extensible for more keyboard sounds or UI features

## Getting Started

### Prerequisites

- Node.js (v18 or newer recommended)
- npm

### Installation

```bash
npm install --legacy-peer-deps
```

### Running the Development Server

```bash
npm run dev
```

### Building for Production

```bash
npm run build
```

## Project Structure

```
components/
  ui/
    select.tsx      # Custom select component
public/
src/
  ...
```

## Customization

- Add your keyboard sound files to the `public/` directory.
- Update components to use your custom sounds or UI.

## Troubleshooting

- If you see dependency errors, use `npm install --legacy-peer-deps`.
- For hydration errors, ensure you do not use non-deterministic values in SSR components.
